    Suspect image

      LSB plane

      Each pixel shows only its lowest bit. Natural pictures show faint structure; hidden data shows up as random noise.

      Method: LSB replacement writes a 4-byte tag (STG1), a 4-byte length, then the message into the lowest bits of the red, green and blue values. A password encrypts the message with AES-256-GCM (key derived by PBKDF2), so only someone who knows it can read the message.

      Use only on files you own or are authorised to test.
